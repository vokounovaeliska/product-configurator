# Frontend Monorepo

Frontend applications and shared packages.

## Apps

- **nextjs** - Next.js 15 application (port 3001)
- **storybook** - Component documentation

## Quick Start

```bash
# From root directory
pnpm frontend:dev
```

## Packages

- `@workspace/ui` - Shared UI components
- `@workspace/eslint-config` - ESLint configuration
- `@workspace/typescript-config` - TypeScript configuration
- `@workspace/prettier-config` - Prettier configuration
